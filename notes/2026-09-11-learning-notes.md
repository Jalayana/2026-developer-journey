Worked on: Connecting BINGoals data to the dashboard using JavaScript.

Learned: Functions can process data and return a value that can then be used to update the DOM.

Revisited: querySelector() for DOM selection and .textContent for changing displayed text.

Practice: DOM manipulation, template literals, functions/return values, and working with arrays of objects.

Key mental model: Data → Logic → DOM → User sees result

Key Mental Model:
Data: “What information do I have?”→ Logic: “What do I want to do with that information?”→
DOM: “Where should that result appear on the webpage?”→
User: “What does the user actually see?”

So Data gives JavaScript the information →
Logic processes the information →
DOM manipulation puts the result onto the webpage →
User sees the updated information.
