Project Vision
The vision of this project is to develop an app that caters to those who want to set and keep track of their goals while gamifying the process to keep interest.

Problem Statement
Pen and paper can't show you your progress while you are in the process of creating goals, BINGoals will be able to.

Target Audience
BINGoals is designed for people who enjoy setting personal goals and want an engaging way to track them.

MVP Features
-The minimum viable product features will be:
Dashboard view
Bingo board view
Display goals
Display progress percentage
Navigation between the two views

Future Features

Data Model-What information needs to be stored
